Privacy Policy

Effective date: 5 September 2026

DJ Davidinho Studio is a personal Windows desktop application used by the DJ Davidinho music project. This policy explains how information is handled when connected services are used.

1. Data the app may access

When the user explicitly connects a third-party service through OAuth, DJ Davidinho Studio may access only the permissions approved by the user. For TikTok, the current integration is intended to access basic profile information and public video data, including public engagement metrics made available by TikTok.

2. How data is used

Connected-platform data is used inside DJ Davidinho Studio to organize content, link social posts to music projects, display analytics, create historical snapshots and generate local performance insights.

3. Local storage and security

DJ Davidinho Studio is local-first. Application data is stored on the user's own computer. OAuth credentials and tokens used by supported integrations are stored locally using Windows secure storage where implemented by the application.

4. Sharing and sale of data

DJ Davidinho Studio does not sell, rent or provide connected-platform data to advertisers. The application is not an advertising service and is not a data-broker service.

5. Optional AI features

Some optional features may use a locally configured AI model or an external AI provider selected by the user. When an external AI provider is deliberately used, only the information needed for the requested feature is sent according to the user's configuration and the provider's own terms and privacy policy.

6. Data retention and deletion

The user controls the local application data. The user may disconnect a connected service, revoke its authorization through the relevant platform, or remove local application data. DJ Davidinho Studio does not maintain a separate hosted copy of TikTok account data for this personal desktop integration.

7. Third-party services

Third-party services such as TikTok, YouTube, Instagram/Meta and optional AI providers operate under their own terms and privacy policies. DJ Davidinho Studio is not affiliated with or endorsed by those companies.

8. Contact

For privacy questions related to DJ Davidinho Studio, contact djdavidinho.music@proton.me.
