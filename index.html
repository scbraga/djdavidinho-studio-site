Purpose of TikTok integration

The TikTok connection is used to let the owner of the DJ Davidinho account authenticate securely and read the account's basic profile information and public videos, when explicitly authorized.

DJ Davidinho Studio does not sell TikTok data, does not run advertising, and does not provide TikTok data to advertisers.
